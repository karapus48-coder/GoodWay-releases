# GoodWay: обновления приложений

С версии 0.8 GoodWay — это два приложения для Android из одного кода.

* **GoodWay** — для пассажиров: [скачать goodway.apk](https://github.com/karapus48-coder/GoodWay-releases/raw/main/goodway.apk). Номер последней версии — в `version.json`.
* **GoodWay Водитель** — для водителей, работает только с логином и паролем от администратора: `goodway-driver.apk`, версия в `version-driver.json`.
* **GoodWay Демо** — служебная сборка с обоими разделами для проверки на одном телефоне без сервера: `goodway-demo.apk`, версия в `version-demo.json`.

Каждое приложение читает свой файл версии, чтобы показать на колокольчике, что вышло обновление.
